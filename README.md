# Venus Space

**A beginner Python project exploring the connection between Computer Science and interior design.**

Venus Space is a personal project I am building while learning Python. The goal is to gradually turn a simple command-line program into a more complete interior design and room planning application.

## Current Status

**Venus Space v0.1 — In Development**

Current features:

- Room name input
- Interior style selection
- Main color selection
- Favorite material selection
- Room dimension input
- Area calculation
- Compact / Medium / Spacious classification
- Budget input
- Room summary
- Basic recommendation

## What I Am Learning

- Python variables

- `if / elif / else`
- Lists and indexes
- `for` and `while` loops
- Input validation
- `try / except`
